# OTML Practical 5: Optimization using Gradient Descent

. 1. Title

**Optimization using Gradient Descent for Linear Model Parameter Learning**

. 2. Objective

The objective of this practical is to understand how **Gradient Descent** is used as an optimization technique for learning the parameter of a simple linear machine learning model.

After completing this practical, students will be able to:

- Understand the concept of Gradient Descent.
- Understand how loss or cost is minimized iteratively.
- Learn how model parameters are updated step by step.
- Understand the role of learning rate in optimization.
- Connect optimization concepts with machine learning model training.

. 3. Theory

Gradient Descent is an optimization algorithm used to minimize the error or cost function of a model.

In this practical, a simple linear model is considered:
